# Dedicated sub-resource endpoints: worker controller mappings of the child-resource shape
#   /api/<parent>/{var}/<literal>  or  /api/<parent>/{var}/<literal>/<literal|{var}>
# that a dedicated controller serves instead of DynamicCollectionRouter's generic
# {parentName}/{parentId}/{childName}[/{childId}] handlers. Spring ranks the literal segment
# above the router's {childName} variable, so the trailing segment names an operation, not a
# child collection: RouteAuthorizationFilter keeps the parent route's own decision for these
# requests even when a tenant has a collection named like that segment.
#
# Format: one "METHOD /api/..." per line ("*" = any method); "{x}" matches exactly one path
# segment; '#' starts a comment. Kept in step with the worker's controllers by
# kelta-worker DedicatedSubResourcesDriftTest, which fails on a missing or stale line.
