## What the AGPL asks of you

- If you **modify** Kelta and let users interact with the modified version over a network, you must offer those
  users the corresponding source of your modified version under the AGPL.
- Running an **unmodified** Kelta for your own organisation or your customers carries no obligation to publish
  anything.
- Applications you build *on* Kelta — collections, flows, pages, modules you install, code that calls its API —
  are yours; the license covers the platform, not the metadata and data you put into it.

For questions about other licensing arrangements, open a discussion with the maintainers on
[GitHub](https://github.com/kelta-io/kelta).
